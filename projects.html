Projects

  • Containerized Web Portfolio: Developed this personal portfolio website using HTML, CSS, and JavaScript to showcase academic background, technical projects, and contact information. The site was containerized using Docker for consistent deployment and hosted on Microsoft Azure for public access.
  • HCI MoodMeal App: Designed a prototype web app that recommends meals based on user mood input using a matching algorithm. Focused on usability and personalization. Developed as part of a Human-Computer Interaction unit to explore emotional design in user interfaces.

The program featured dynamic graphs to display influencers' growth with options to view data on a monthly, yearly, or quarterly basis. Made over the course of a semester in Eclipse IDE using Java.
